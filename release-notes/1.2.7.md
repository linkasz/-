# 课表+ 1.2.7

- 课程与待办事项整合到今日时间轴，课程详情可查看关联任务；待办支持分组、子任务、优先级、置顶、重复规则与桌面组件。
- 支持从文字、图片和 Android 分享内容提取待办，并提供月历/周历、系统日历同步、效率概览及完成动效。
- 默认使用纯白背景，可通过单一壁纸入口选择图片、实况图或静音循环视频。
- 新增课表+ 自有 GitHub Release 更新检查；默认只查正式版，Beta 需主动开启；安装前校验版本、包名与 SHA-256，并交由 Android 系统确认。
- 沿用 SleepDown `.sleepdown` 备份格式，备份包含待办，并保留旧包名备份迁移路径。
