# 人格、上下文工具、朗读与待办日历交付记录

本轮针对用户确认的四组需求修改。保留既有工作树、数据库、用户资料、包名与签名；不安装、不推送、不发布。代码修改以当前本地源码为准，历史轮次记录不代表本轮实机结果。

## 实现与修改原因

### 人格与提示词边界

- 读取指定目录的全部 42 份 Word 文档，形成 38 个角色；同角色的不同版本合并，世界树资料作为对应角色背景。逐文件的 SHA-256、角色对应关系见 [来源映射](2026-10-01-persona-source-map.json)。原始文档未修改。
- 每个角色重新定义身份、语气、回复长度、能力边界、课程/待办/时间/位置/偏好上下文以及输出方式。保留角色辨识度，去除强制恋爱关系、动作旁白、内心独白和数值状态栏对实用助理的干扰。
- 三款原有风格和用户自定义继续可用；首次库包含 38 个来源角色、三款内置风格和一个自定义角色。旧自定义偏好及已选风格继续迁移。
- 内部定义使用 `meta / visiblePrompt / corePrompt`，公开卡片与备份使用不包含核心字段的业务 DTO。预览、编辑和复制只取 `visiblePrompt`，停用、默认选择和编辑经过统一校验。
- 按本轮已确认的本地隔离方案使用 repository 预览入口，没有引入 HTTP 后端。核心只在向已配置模型发起请求时组装；不会作为预览、剪贴板、日志或备份返回。应用是本地客户端，APK 与模型请求仍包含运行所需核心内容，本方案不提供 APK 防提取保证。
- 停用当前默认人格时选择另一款启用的内置风格，避免出现没有可用默认角色的状态。旧备份缺省新增字段；新备份只往返业务配置并拒绝注入核心字段。

主要入口：`AgentPersonaRepository.kt`、`AgentPersonaDialog.kt`、`DayAgentPreferences.kt`、`BackupCodec.kt`、`assets/personas/catalog.json`。

### 实时回答、上下文与朗读一致性

- 百炼三款 Omni 实时模型直接回答，不再将语音转写交给另一个文本模型重新回答。实时会话请求文字输出，完整回复校验、持久化并展示后，再用独立 HTTP TTS 朗读该消息。
- 默认专用朗读模型为 `qwen3-tts-flash`、音色 Serena。ASR 模型继续转写后交给用户配置的文本助理；其他平台沿用分段合成或系统朗读路径。自动朗读开关保留。
- TTS 纯文本化复用聊天 Markdown 解析器：链接使用界面显示的标签、表格按显示顺序读单元格，数字和语义不改写。删除原先让实时模型二次生成朗读稿的路径。
- 原生语音和文本助理共用课程、日程、位置、时钟工具执行器；原生平台的工具包装按各自协议构造。百炼 Omni 注册并执行四个 `get_my_* / get_current_*` 工具，ASR 路径由后续文本助理执行同一组工具。
- 每轮刷新课程事实与当前时间，查询实际课程起止时间、有效待办及用户授权的位置，不猜测城市。时钟、位置不进入跨轮缓存，后台线程执行工具避免阻塞界面。
- 活动查询提示示例要求同时查询课程和日程。用户给出活动起止时间时计算同日区间交集；只有截止时间的任务按时间点处理，全天或未知时间明确标记不确定。未给出时间段时先列出明日安排、再询问活动时间，不凭空声称没有冲突。
- 原生回复使用请求队列、会话标识、响应 ID 和一次消费保护，工具继续回复也跟踪同一轮。旧回调、重复响应与已取消的结果不能覆盖新会话。
- 格式修复最多一次，复用本轮事实并禁用修复轮的工具，避免重复查询或执行。创建仍只生成草稿，确认前不写入。朗读失败保留已显示的消息并提供重试，重试不会再次请求回答模型。
- 离页、后台、切换平台及音频焦点丢失释放连接、录音与播放。失败提示不包含凭据或原始录音。点击打断已实现；真实设备上的回声、低延迟及持续多轮效果仍须验收。

主要入口：`AgentContextTools.kt`、`AgentToolFactCache.kt`、`NativeVoiceBridge.kt`、`NativeResponseTracker.kt`、`RealtimeVoiceProtocol.kt`、`VoiceSession.kt`、`VoiceReplyText.kt`、`AgentMarkdown.kt`。

### 百炼音色

- 独立配置包含 48 款官方内置音色及官方样例链接，提供语言、性别筛选、选择、试听和停止。空目录、读取失败、刷新中和试听失败都有可见状态。
- “刷新官方音色”解析官方文档的非实时 TTS 表格，校验目标模型和数量后才更新缓存；不把 Omni 音色混入专用 TTS。
- “账号音色”使用官方语音注册查询接口分页拉取，按目标朗读模型过滤；无兼容自定义音色时保留内置选项并说明原因。它不是公开内置音色列表 API。
- 内置试听优先播放官方样例，不发送模型请求；无样例的自定义音色明确提示会调用 TTS 合成固定试听文本。停止试听、关闭页面和后台都取消播放任务。
- API Key 沿用加密存储，不进入备份、交付报告或日志。地域与业务空间沿用配置，账号是否开通具体模型不能由本地编译证明。

主要入口：`AliyunTtsVoices.kt`、`AliyunTtsClient.kt`、`AliyunTtsSettings.kt`、`VoicePreviewPlayer.kt`、`assets/voices/aliyun-tts.json`。

### 待办分组、列表与日历

- 分组面板选择全部、未分组、最近删除后保留面板，下方直接显示对应卡片，首页同步筛选。统一数据选择函数，数量与列表使用相同规则；清理旧课程过滤状态，避免有数据却被隐藏。
- 三个切换项使用公共等宽按钮组件，同一行排列；按真实字体测量决定整行降级为图标，保留数量、长按提示与无障碍标签。其他人格/平台/音色操作组也复用公共响应式按钮。
- 列表保留加载骨架、空状态和异常重试。最近删除复用原卡片，提供恢复和永久删除确认，沿用原 30 天及批次语义；不修改数据库版本。
- 日历左右切换与课程页共用 `AppDirectionButton`：34dp 视觉、18dp 图标、至少 48dp 点击区域。复用公共玻璃入口和设计参数，保留课程手势排除逻辑。
- 顶部年月可点击，玻璃浮窗支持 1900–2100 年与十二个月；点击月份立即跳转，日期按目标月有效天数限制，旧浮窗锚点清理。遮罩、返回和 ESC 取消，不提交草稿年份。

主要入口：`TodoListSelection.kt`、`TodoViewModel.kt`、`TodoActivity.kt`、`TodoMonthPicker.kt`、`WeekScheduleUi.kt`、`AppDirectionButton.kt`、`AdaptiveGlassTabs.kt`、`AdaptiveGlassActions.kt`。

## 实机验收步骤

1. 设置 → AI 助理 → 人格：搜索并选择来源角色，打开预览/复制/编辑；停用当前默认、重新启用和设为默认。导出备份，确认只有业务配置，恢复旧备份仍保留自定义偏好。
2. 配置北京或对应地域百炼凭据，分别选择三款 Omni。问“明天有没有课”“明天 10 点到 11 点参加活动是否冲突”；核对本机课程与待办、位置拒绝后的提示。ASR 模型仍由已配置文本助理回答。
3. 开启自动朗读：核对同一气泡的文字、数值、表格和播报；断网使 TTS 失败后点重试，聊天中不得出现第二个回答。切换全屏/浮窗、快速停止再开始、返回后台检查旧响应未覆盖新会话。
4. 百炼朗读设置：语言/性别筛选、48 款内置选择、官方刷新、试听/停止、账号音色空状态及失败重试；后台和离页不继续播放。
5. 待办分组面板分别选三组，有数据时可直接看到卡片，空组显示空状态；恢复或删除后数量与首页同步。窄屏和大字体下三项仍同行、图标提示可读。
6. 日历左右按钮与课程按钮对比；选择闰年二月、月底切月、跨年，检查有效日期。遮罩/返回/ESC 取消，选月份跳转，键盘及旋转后无失效锚点。

## 交付与风险

- `时序清单-v1.0.1-正式版.apk`：本地正式签名包，包名 `com.scheduleplus.student`、versionName 1.0.1、versionCode 36。
- `时序清单-修改文件清单.json`：本轮源码路径与 SHA-256；保留本轮前工作树快照作比较，未混入任务外变更。
- `时序清单-本轮业务改动.diff`：公开业务、界面及传输的可审阅子集，主动排除核心提示词正文和私有组装实现，不是全量补丁。完整实现保留本地源码，文件清单可核对。
- 官方文档表格结构变化可能影响音色刷新，刷新失败保留现有目录；模型/音色可用性以账号地域和权限为准。原生服务协议和音频性能需真实服务与设备验收。
- 角色风格是模型行为偏好，不替代事实校验、权限或用户创建确认。文本提示词不能保证模型永远不泄露，输出边界检查用于阻止可识别的协议和核心回显。
