## 当前语音语义

1. 用户明确要求实时语音模型将语音转成文字，然后交给已经配置的 AI 助理回答。
2. 不再让语音模型通过函数调用生成另一个助理答复；原生语音会话关闭自动回答，最终转录走原有 DayAgentRunCoordinator。
3. 用户随后要求保留自动朗读并提供开关。`设置 → AI助理` 增加语音平台与模型入口和自动朗读开关；独立于凭据保存，默认开启，重启保留，下一次开启语音生效。语音配置面板也使用同一开关。
4. 朗读只接收最终答案的可显示文本，不包含推理段或操作 JSON。关闭朗读后恢复聆听，保留文字回复。
5. 百炼增加专用 `qwen3-asr-flash-realtime` 与 `2026-02-10`、`2025-10-27` 版本，使用 16 kHz PCM、服务端 VAD、实时 partial/final 转录。专用 ASR 的朗读使用系统 TTS；朗读时不向 ASR 回传麦克风，避免识别自己的播放。
6. 硅基流动增加 SenseVoice/TeleSpeech 与 CosyVoice/MOSS 的四种识别/合成组合。官方公开接口是文件识别及流式 PCM 合成，不称为原生实时 WebSocket。旧默认组合标识保留。
7. 转录按 item_id 去重，服务端结束说话后超过 20 秒未返回转录时停止并提示。关闭、离页、后台和音频焦点转移释放录音、播放和连接。

## 文件与兼容边界

- `ReferenceVoiceCrown.kt`：玻璃球、点阵、问答卡片和顺时针彩光；RMS 与动画时钟在 Canvas 读取，避免每个采样重组整个对话。
- `DayAgentUi.kt`：新紧凑语音呈现、完整展开模式与现有工具确认交接。
- `VoiceSettings.kt` / `VoiceUi.kt` / `SettingsScreensUi.kt`：模型、设置入口与持久朗读开关。
- `SiliconVoicePresets.kt` / `RealtimeVoiceProtocol.kt` / `VoiceSession.kt`：模型路由、实时转录、现有助理回答与朗读控制。音量采样使用原子更新，避免采样线程覆盖会话阶段。
- `VoiceReplyText.kt`：仅有操作建议的回复仍显示展开确认入口；数据操作继续使用原来的确认流程。
- 不改变应用身份、版本、Room、备份、课程与待办数据。保留已有工作树，不推送或发布。
