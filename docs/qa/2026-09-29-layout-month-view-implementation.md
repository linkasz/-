# 页面布局与课程月视图实现记录

日期：2026-09-29  
版本基线：1.2.8 / versionCode 35  
分支：`codex/calendar-sync-orphan-recovery`

## 已修复的代码问题

- 课程主页面新增周一至周日月历；日期格用标记提示有课，选择日期后按开课时间显示课程。日期查询复用 `coursesForDate`，因此遵循既有学期范围、调课和单双周规则；课程在学期外时显示空状态。
- 课程日/周/月切换复用既有模式状态。课程模式内容的内层动画在 Dock/主页转场运行期间关闭，避免两层页面动画同时运行；周/月之间仍保留轻量弹簧淡入淡出。
- 待办、日历和洞察子页已有独立顶栏下内容留白；待办子页动画可在主页面转场期停用。待办日历将日期索引预先构建一次，任务列表、父子任务映射及洞察统计使用记忆化结果，减少滚动与切页中的重复遍历。
- 待办图标按钮和操作按钮统一使用液态玻璃入口及至少 48dp 触控尺寸。待办区域文字颜色和进度轨道现按玻璃前景样式取值，避免暗壁纸下仍使用深色正文；近 7 天图表中的零值显示为弱基线，不再绘制成实色数据柱。
- 待办日历由固定 42 格和嵌套任务列表调整为按月份实际周数生成的 4–6 行网格；日历和当天任务共用一个滚动容器，日期格按字体内容扩展高度并提供读屏描述，避免小窗口下任务区被固定日历挤压。
- 待办日期跨月切换会同步调整当前选中日期；数据操作错误通过现有页面提示展示。本轮没有数据库、备份或组件协议变更。
