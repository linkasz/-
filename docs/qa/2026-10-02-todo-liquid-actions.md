# 全选、取消、删除所选：液态玻璃材质

## 改动

仅修改 `feature/todo/TodoActivity.kt` 的 `TodoDeleteActions`。三枚按钮复用现有玻璃入口、壁纸自适应配色及公共按钮尺寸；取消、选择、删除确认和归档逻辑没有改动。

- 去掉 `selected=true` 带来的不透明覆盖色，让背景采样真实透出。
- 复用公共 control 材质：模糊 4dp、边缘折射 12dp / 24dp、高光、内外阴影及原有按压反馈。
- 浅色底色透明度 0.52、暗色 0.56，均保留清晰边框；禁用仅将文字降到 0.80，不降低整枚按钮透明度。删除可用时采用红色玻璃 tint 和红色文字。
- 等宽、50dp 高、窄屏图标与 Tooltip 沿用原实现。无 Backdrop / 不支持模糊时沿用公共 GlassSurface 的可读降级。
