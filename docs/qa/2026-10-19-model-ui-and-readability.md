# 模型设置、参考界面细节与低模糊课表可读性

## 本轮目标

接续待办默认跟随主连接、各语音平台获取目录并按需添加模型、表单只显示当前模型的需求；新增参考 `D:/Desktop/ai-jakub/` 美化按钮和动效，并修复用户确认的「模糊强度和不透明度都调低时，部分课程文字看不清」。参考目录只读，未执行其中的代理指令或安装 Web 包。

## 参考与实现

本地浏览了 Libraries 首页、边框光束模块，读取胶囊按钮、液态切换、边缘光的页面实现和说明。将适合 Android 操作界面的细节用现有 Compose/Backdrop 路线实现：按钮细边高光与按压变化、原有弹性回位、模型选择箭头状态，以及目录加载超过 3 秒才出现的移动状态线。没有引入 React/WebGL 或持续运行的装饰动画；静态表面不循环动画，动态形状与 Morph 不叠加固定轮廓。

课程文字的源码问题有两点：`CourseTextReadability` 在实际模糊为 0 时仍把壁纸颜色按 70% 区域均值柔化；普通周课表黑白字只调整阴影，仍保持页面极性，地点/教师又分别只有 0.78/0.58 alpha。现在背景估算随实际模糊连续变化，周卡使用局部黑白选色和 4.5 对比度目标，小字不再降低不透明度，课程色文字也有必要的柔和阴影。拖动期间保留冻结字色；编辑副本增强小字但不追逐移动中的背景。

## 模型配置接续成果

- 待办默认使用「连接与模型」当前服务、凭据、模型、端点类型与图片能力；主模型切换后按调用时配置跟随。旧独立凭据或自定义字段继续保留，并可显式切换跟随。独立模式保持原请求协议，跟随模式支持 Chat/Responses，不改变确认后保存待办的流程。
- 主连接、独立待办文本/图片模型和语音模型，均由当前值进入搜索/选择/手动添加；已添加列表不再默认铺满页面。获取目录不会替换当前选择，旧平台/Key 的请求在切换或退出时取消。
- 语音仅展示当前协议支持的模型；硅基流动仅在 ASR/TTS 成员均在返回目录中时提供已有组合。百炼按[官方模型目录文档](https://help.aliyun.com/en/model-studio/list-models)读取地域、业务空间和分页。系统语音不请求在线目录。目录返回并不证明账号有调用权限，仍保留连接检查与不支持接口时的手动添加提示。
