## 验证事实

历史 1.0.2 数据链路测试及过去设备截图属于此前交付，不作为本轮视觉验收证据。当前定向测试覆盖配色滞回、复杂背景预算、扩张上限与 reduced motion，以及既有菜单定位、Dock 拖动、开关状态、滑块交互规则；最终结果与 APK 摘要在本记录的交付核对部分列出。

API 26 与 API 36 系统镜像已安装，本轮测试 AVD、密钥和日志保存在工作区临时目录。所有设备操作指定模拟器与隔离 ADB 端口；未重启 ADB 服务、未安装或启动 USB 手机应用。旧测试进程出现 Suspended，恢复仅限确认过的工作区 SDK 测试进程。重新启动后，API 36 WHPX、API 26/36 软件加速均退出 `3221225477`（`0xC0000005` 访问冲突），没有完成有效截图采集。

因此本轮**没有同条件前后截图，也没有原生渲染或手机帧率验收结论**。待验：明暗/高细节/混合背景、窄屏和大字体、快速连点与取消、反向拖动、菜单退场/二级返回/外部关闭、IME，及重影、黑块、图标漂移、边角裂纹与点击范围错位。编译和规则测试通过不能替代这些项目；候选包保留“待视觉验收”状态。
