# 1.0.2 公开构建与本地完整版

公开源码的 `app/src/main/assets/personas/catalog.json` 中 38 张来源人格的 `corePrompt` 均为空，`AgentPersonaRepository` 的核心常量也为空。保留可见风格、身份设置、历史、事实工具，以及代码实现的草稿校验和用户确认流程。

来源映射采用匿名编号，不提供原始文件、原始文件名或原始文件摘要。历史 QA 中的人格数量与本地构建结果是当时记录，不证明公开版包含真实核心。

本地完整版保留真实核心，人格表现可能不同。两版采用相同包名 `com.scheduleplus.student`、版本 `1.0.2 / 37`、Room 45 和现有签名，可覆盖升级；覆盖安装公开版会使用公开占位核心。

GitHub 分发仅使用公开版 APK 和由它生成的更新清单。本地完整版、签名凭据、私有后端、原始人格文档及用户数据不进入仓库或 Release。

公开构建强制将 `SLEEPDOWN_REMOTE_CONFIG_SECRET` 设为空，不从本地签名配置继承后端凭据；用户可自行配置的 AI 服务入口保留。
